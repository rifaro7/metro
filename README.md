# 🚇 Metro Rail Ticketing System (C Language)

A terminal-based Metro Rail Ticketing System written in C. This program allows users to buy and cancel tickets, calculate travel costs based on distance, and simulate mobile/online banking payments.

---

## 📋 Features

- Buy metro tickets between five predefined stations.
- Limit ticket purchases to a maximum of 4 per transaction.
- Calculates fare based on station distance.
- Simulates payment via:
  - Mobile Banking (bKash, Nagad)
  - Online Banking (VISA, MasterCard)
- Cancel tickets using a unique ticket number.
- Stores ticket data in a local `ticketdb.txt` file.

---

## 🖥️ Requirements

- GCC compiler
- macOS or Linux terminal
